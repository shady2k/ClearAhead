# Воркер G — починить server/maps/st_a.json: восточная горловина не смыкается

Сначала прочитай `.internal/briefs/COMMON.md`. Go-модуль в `server/`.

## Ты владеешь
- `server/maps/st_a.json` — **и только его.**

## Чужое, не трогать
Всё остальное. В частности `server/internal/track/acceptance_test.go` — это твой
измерительный прибор, читай и запускай, но **не правь**. Подгонять тест под карту
запрещено: чинить надо карту.

## Задача
Карта написана предыдущим воркером и **не проходит компиляцию**:

```
track: невязка замыкания в порту ST_A_SW_E1.D через ST_A_SW_E1:diverging:
52195.4557 мм по плану, 0.0000 мм по высоте
```

52 метра. Высота сходится (станция плоская), расходится только план.

## Что уже известно — не переоткрывай
Восточная горловина **проезжается в обратную сторону**: общий порт `.C` смотрит на
выход со станции, а пути входят в `.S` и `.D`. Это правильная топология для
зеркальной горловины.

Предыдущий воркер отзеркалил рукость (`left`) и знаки углов, но соединительные
рёбра каскада оставил по западному шаблону:

```
ST_A_E_E12: SW_E1.D -> SW_E2.C  [straight(14.731) + arc(300, -0.1107)]
ST_A_E_E23: SW_E2.D -> SW_E3.C  [straight(14.731) + arc(300, -0.1107)]
ST_A_E_E34: SW_E3.D -> ST_A_T4_E.P1
```

**Гипотеза координатора (проверь, не верь на слово):** при обратном ходе смещение
в 5,3 м набирается в другом порядке, поэтому «вставка, потом контр-дуга» неверна —
нужна другая последовательность и/или другие длины. Возможно также, что неверна
сама привязка портов: у восточной стрелки путь приходит в `.S`, а `.S` определяется
прямым проходом от `.C`, и одновременно тем же портом кончается ребро пути длиной
850 м — вот эти два и обязаны сойтись.

## Как чинить — итеративно, у тебя есть прибор
```
cd server && go test ./internal/track/ -run TestStationCompiles -v
```
Сообщение об ошибке называет **порт и величину невязки в миллиметрах**. Меняй
геометрию, гоняй тест, смотри, как число уменьшается. Это и есть цикл работы.
Предыдущий воркер этого прибора не имел — поэтому и не смог проверить восток.

## Напоминание про геометрию горловины
Угол крестовины 1/9 = arctan(1/9) ≈ 0,110657; в карте используется **0,1107**,
считай тем же числом. Стрелка: прямой проход — прямая 33,5 м; отклонённый — дуга
радиусом 300 м на ±0,1107. Междупутье станционное — **5,3 м**. На западе оно
набирается как «дуга стрелки, затем прямая вставка 14,731 м, затем обратная дуга
того же радиуса»; две дуги 1/9 без вставки дают только 3,67 м.

## Ограничения, которые нельзя нарушать
- Ровно **один якорь** на всю станцию (`ST_A_W.P1`). Не добавляй якорей, чтобы
  «развязать» невязку — это заглушит проверку, а не починит карту.
- Допуск замыкания 1 мм по положению и 1e-5 рад по направлению. Не трогай его.
- Порт обслуживает максимум два элемента; конец линии обязан иметь `purpose`.
- Станция остаётся плоской: вертикальных цепочек нет.
- Состав станции не менять: четыре пути, две горловины, тупик отстоя, подъездной.

## Критерий приёмки
```
cd server && go test ./internal/track/ -run TestStationCompiles -v
```
проходит. Никаких правок вне `server/maps/st_a.json`.

В отчёте: какая была причина невязки на самом деле, совпала ли с гипотезой
координатора, и какие числа поменял.
